01 / Method

Architecture overview

A multiscale U-shaped network combining local spatial guidance and global Fourier-domain guidance. It uses invertible coupling during spatial fusion and amplitude/phase fusion during reconstruction.

Spatial guidance

The released coupling blocks fuse MS and PAN at multiple resolutions using the original LU-parameterized mixer.

Frequency guidance

Three Fourier processing blocks fuse amplitude and phase at their original resolutions, with the released normalization and reconstruction.

Dual-domain reconstruction

Spatial-frequency features are recombined in the original sequence, followed by the original attention head and MS residual.

03 / Compatibility-first implementation

Modern code. Original model.

The modern package retains the published state-dict keys, model structure, active operators and original source. It provides an explicit inference API, strict weights loader, paired NPZ data, regression tests and a CLI.
